Inventory Management and Logs need to be set up in the **Management Hub.**

Don’t know how to access **Management Hub** ?  [Click Here to learn how to access Management Hub.](http://localhost:5173/docs?id=How-to-access-Management-Hub)

1\.	Go to **Inventory > Inventories** to view your inventory items.

![](</admin/8.Invenory Management Logs/8.1/1.png>)

2\.	If an item does not appear in the inventory list, check whether **Inventory Tracking** is enabled for that item. Go to **Items** and select the item.

![](</admin/8.Invenory Management Logs/8.1/8.0.1.png>)

3\.	Turn on the **Inventory Tracking** button (e.g. Coffee).

![](</admin/8.Invenory Management Logs/8.1/8.0.2.png>)

4\.	Return to **Inventory > Inventories**. The item will now appear in the inventory list.

**Note**: If an item has **variants**, each variant will be listed separately in the inventory. For example, **Coffee with Large, Medium, and Small** variants will appear as separate items, with each variant having its own inventory quantity.

![](</admin/8.Invenory Management Logs/8.1/8.0.3.png>)
